# 정비맵 (가칭)

당사 정비사업장을 지도에서 고르면 **사업장 기본정보 · 반경 안 아파트 실거래 시세·평당가 · 인근 청약 일정 · 입주(공급) 예정 단지**를 한 번에 보는 앱입니다.
[분양시장 레이더](https://younguk06-sonny.github.io/New-Build_Rader/)의 자료와 [자두](https://younguk06-sonny.github.io/myeongso/)의 지도·저장 틀을 합쳤습니다.

주소: `https://younguk06-sonny.github.io/jeongbi-map/`

## 어떻게 돌아가나
```
매일 07:17  분양시장 레이더(New-Build_Rader) ── 국토부 실거래가·청약홈 수집
매일 08:07  이 저장소 Actions ── 레이더 저장소 자료를 받아 site/data 를 만들고 GitHub Pages 배포
화면        카카오맵으로 지도 표시·단지 위치 찾기 (찾은 위치는 각 기기에 저장해 두고 다시 쓰기)
```
- 따로 넣을 API 키(시크릿)가 없습니다. 레이더가 키를 갖고 수집하고, 이 앱은 레이더가 저장한 결과만 씁니다.
- 카카오 지도 키는 자두와 같은 키를 씁니다(같은 `younguk06-sonny.github.io` 주소라 그대로 동작).

## 처음 한 번 설정
1. 저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 바꾸기
2. **Actions** 탭 → `자료 만들기 및 배포` → **Run workflow**

## 사업장 고치기
`site/data/sites.json` 한 파일만 고치면 됩니다. 공개 사이트이므로 **공개된 수준의 정보(위치·유형·세대수·시공사·진행단계)만** 넣고 비례율·분담금·위험등급 같은 내부 수치는 넣지 않습니다.

| 항목 | 뜻 |
|---|---|
| `lat`, `lng` | 지도 위치(대략). 앱의 **📌 위치 맞추기**로 옮기면 나오는 값을 붙여 넣으면 모두에게 반영 |
| `q` | (선택) 아파트 단지명처럼 이름이 분명할 때 카카오 장소 검색으로 위치를 다시 잡음 |
| `stage` | 진행 단계(공개 수준) |
| `area` | (선택) 구역 경계 꼭짓점 `[[위도, 경도], ...]`. 앱의 **✏️ 구역 그리기**로 그리면 나오는 값을 붙여 넣으면 모두에게 경계·면적 표시 |

## 숫자 읽는 법
- **평당가**: 전용면적 기준(만원/전용 3.3㎡). 최근 12개월 거래를 건수로 가중평균. 12개월 거래가 없으면 36개월 값을 흐리게 표시
- **최근 분양 평당**: 최근 3년 청약 단지 분양가를 같은 전용면적 기준으로 환산(공급면적 기준 값은 단지를 열면 함께 표시)
- **입주 예정**: 최근 3년 분양을 마친 단지 중 입주 예정월이 남은 단지

## 정비구역 레이어 (아실식)
지도를 확대하면 전국 정비구역이 유형별 색으로 칠해지고, 더 확대하면 **사업명 / 진행단계** 라벨이 붙습니다. 구역을 누르면 진행단계 막대와 그 구역 기준 주변 시세·청약이 열립니다. 🗂️ 버튼에서 유형별로 켜고 끌 수 있어요(준공 구역은 기본 숨김).

| 지역 | 자료 | 담긴 정보 |
|---|---|---|
| 서울 | 서울 열린데이터광장 「도시계획사업(서울플랜+)」 SHP (OA-22712) | 경계 + 사업유형 + **추진단계**(연번부여·추진위·조합설립·사업시행·관리처분…) |
| 그 외 | 브이월드 「(연속주제) 도시및주거환경정비 정비구역」 시도별 SHP | 경계 + 구역명 + 고시일(정비구역 지정 단계까지) |

자료를 새로 받으면 아래처럼 다시 만들고 커밋하면 됩니다(외부 라이브러리 불필요).
```
python3 scripts/build_zones.py --seoul UPIS_C_UQ120.shp --nat LSMD_CONT_UD602_*.shp --asof-seoul 2026.09 --asof-nat 2026.10
```

## 지역 세부내용 (왼쪽 창 아래)
지금 보는 지역의 실거래가·미분양·공급량·청약·개발호재 핵심 숫자와 추이선을 한 줄씩 보여 주고, 누르면 자세한 화면이 열립니다(단지 비교 1:1·여럿 포함). 지도에서 보고 있는 지역(전국/시도/시군구)을 기준으로 보여 줍니다.
자료는 `scripts/build-data.mjs`가 매일 분양시장 레이더 자료(KOSIS 미분양·인허가·착공·분양, 입주예정, HUG 미분양관리지역, 개발호재, 지역별 실거래)를 `site/data/study.json`으로 요약해 만듭니다.
단지 비교는 실거래가 목록이나 주변 시세 목록의 ＋ 버튼으로 담고(최대 6곳, 이 기기에 저장), 가격 비교는 앞의 2곳을 나란히 봅니다.

## 분양 탭
지도 상단 🏢 분양 탭에서 아파트 / 오피스텔·도시형 / 상가를 켜고 끕니다. 구 단위까지 당기면 화면 안 분양 단지가 `단지명 · 세대수`로 표시되고(접수 예정은 D-day, 청약 중은 색 채움), 누르면 일정·분양가·주택형별 표·경쟁률·주변 시세 대비가 열립니다.
- 아파트: 청약홈 APT 분양정보 (레이더 cheongyak/)
- 오피스텔·도시형생활주택·생활숙박시설·민간임대: 청약홈 오피스텔/도시형 분양정보 (레이더 officetel/, 2026.11 수집 추가)
- 상가: 공개된 통합 자료가 없어 아직 표시하지 않음(LH 단지내 상가 공고 API 연결 시 가능)

## 가격 탭 (실거래가 · 매매가 · 전세가)
지도 상단에서 하나를 고르면 동 단위까지 당겼을 때 화면 안 단지마다 가격 배지가 뜹니다(많이 거래된 단지부터 최대 220곳, 연식 필터). 배지를 누르면 실거래가·매매 평당가·전세가·전세가율과 분기 추이, 최근 거래가 나옵니다.
- 실거래가: 마지막 거래 달의 거래가 중위 / 매매가: 최근 12개월 평당가(전용)
- 전세가: 국토부 아파트 전월세 실거래가(레이더가 cache/rent에 최근 12개월 수집). 공공데이터포털에서 「국토교통부_아파트 전월세 실거래가 자료」 활용신청이 되어 있어야 함
